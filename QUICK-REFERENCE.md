## ⚡ Emergency Contacts

### If Website Goes Down:
1. Contact hosting support immediately
2. Check cPanel for issues
3. Verify domain hasn't expired
4. Check DNS settings

### If Forms Stop Working:
1. Test email receiving
2. Check FormSubmit/Formspree status
3. Try alternative recipient email
4. Check spam folder

### If Hacked/Security Issue:
1. Change all passwords immediately
2. Contact hosting security team
3. Scan for malware
4. Restore from backup
5. Enable 2-factor authentication

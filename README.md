## 📝 How to Update Content

### Update Text:
1. Open the `.html` file in a text editor
2. Find the section you want to change
3. Edit the text between HTML tags
4. Save and reload in browser

### Add Images:
1. Add your image to the project folder
2. Find the `<img>` tag in the HTML
3. Update the `src="your-image.jpg"` attribute
4. Save and reload
